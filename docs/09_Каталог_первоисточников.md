# Каталог первоисточников

**Версия:** 0.3 · 18 октября 2026  
**Назначение:** стабильные идентификаторы для реестра свидетельств, карточек эпизодов и будущей презентации.

> **Ограничение доступа:** это каталог для внутренней исследовательской работы. Большинство исходников в текущем публичном репозитории — неотредактированные документы и стенограммы. До правовой и этической проверки не цитировать их публично и не распространять прямые ссылки. Само присвоение ID не означает, что источник прочитан полностью или пригоден к публикации.

## Уровни обработки

- **A — прочитан частично и пригоден для предварительной аналитики.** Нужно сохранять контекст и проверить полную запись перед прямым цитированием.
- **B — найден по названию, назначение предварительное.** Требуется прочитать содержание.
- **C — вспомогательный актив или документ с неустановленной ролью.** Требуется классификация.
- **P — проектный документ.** Подтверждает содержание замысла/спецификации, а не факт реализации.
- **R — отчёт автора о коде/программе, предоставленный в переписке.** Не равен независимой повторной проверке исходников.

## Производные рабочие документы

Они не заменяют первоисточники:

- `docs/01_Методологическое_ядро.md` — текущая аналитическая формулировка принципов;
- `docs/02_Хронология_пилота.md` — предварительная реконструкция последовательности;
- `docs/03_Реестр_свидетельств.md` — выводы и степень их подтверждения;
- `docs/04_Кейс_для_потенциальных_клиентов.md` — обезличенный внешний черновик;
- `docs/07_Карточки_пилотных_эпизодов.md` — анализ отдельных эпизодов;
- `docs/08_Вопросы_для_проверки_результатов.md` — руководство по верификации;
- `docs/10_Программный_контур_ЭЛИФ.md` — систематизация SRC-022 и последующего уточнения работоспособности;
- `docs/12_Контекст_авторского_замысла.md` — межчатовый контекст замысла и разграничение ролей, не первичное доказательство результатов.

## Правила присвоения идентификаторов

1. Не переиспользовать ID, даже если файл позднее переименован.
2. При появлении версии документа добавить новый ID и указать связь «предыдущая версия / производный файл».
3. Для каждой цитаты фиксировать ID источника и страницу/таймкод.
4. Хранить личные/идентифицирующие сведения только там, где это необходимо для исследовательской задачи.
5. Публичные версии должны содержать только минимально необходимые, проверенные и согласованные примеры.
