# Карта репозитория

## Для чего этот документ

В репозитории смешаны методологические тексты, спецификации, стенограммы, рабочие чаты с ИИ и визуальные материалы. Этот файл даёт логическую навигацию, не меняя и не удаляя исходные материалы.

> Доступ к сырым стенограммам и чатам следует ограничить до проверки приватности. Для внешних коммуникаций используйте только обезличенные производные документы.

## 5. Предлагаемая структура работы

Существующие файлы пока остаются на месте. Новые проверенные материалы складываем в `docs/`:

- `00_Карта_репозитория.md` — навигация;
- `01_Методологическое_ядро.md` — метод в практических терминах;
- `02_Хронология_пилота.md` — последовательность событий;
- `03_Реестр_свидетельств.md` — доказательность и пробелы;
- `04_Кейс_для_потенциальных_клиентов.md` — внешняя история без неподтверждённых обещаний;
- `05_Что_уточнить_у_автора.md` — список вопросов и данных;
- `06_Протокол_ведения_кейса.md` — правила дальнейшей фиксации.

Следующий шаг — после инвентаризации присвоить каждому исходнику стабильный ID (например, SRC-001) и вести ссылки на эти ID в реестре свидетельств. Это надёжнее, чем цитировать материалы без даты и контекста.
