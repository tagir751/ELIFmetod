# Карта репозитория

## Для чего этот документ

В репозитории смешаны методологические тексты, спецификации, стенограммы, рабочие чаты с ИИ и визуальные материалы. Этот файл даёт логическую навигацию, не меняя и не удаляя исходные материалы.

> **Конфиденциальность:** доступ к сырым стенограммам и чатам следует ограничить до проверки приватности. Для внешних коммуникаций используйте только обезличенные производные документы. Перемещение исходника в папку не скрывает его от посетителей публичного репозитория.

## 5. Программный контур

Описание функций по авторскому анализу кода хранится отдельно в `docs/10_Программный_контур_ЭЛИФ.md`. Для отметки фактического использования и свидетельств эффекта заполняется [матрица функций пилота](11_Матрица_функций_пилота.md). Важно не смешивать три вопроса:

1. Что обнаружено в коде?
2. Что реально использовали в пилоте?
3. Какое изменение в работе или обучении удалось подтвердить?

Для второго и третьего пунктов пока требуется сбор дополнительных свидетельств.

## 7. Следующие действия по организации

1. Использовать ID из `docs/09_Каталог_первоисточников.md` во всех карточках эпизодов и реестре свидетельств.
2. Для каждой цитаты фиксировать ID источника и страницу/таймкод.
3. Разделить приватный архив первичных материалов и публичный набор обезличенных материалов.
4. Физически перемещать исходники только после решения вопроса доступа; пока исходные пути не менялись, чтобы не ломать ссылки и сохранить предсказуемость.
