# Карта репозитория

## Для чего этот документ

В репозитории смешаны методологические тексты, спецификации, стенограммы, рабочие чаты с ИИ и визуальные материалы. Этот файл даёт логическую навигацию, не меняя и не удаляя исходные материалы.

> **Конфиденциальность:** доступ к сырым стенограммам и чатам следует ограничить до проверки приватности. Для внешних коммуникаций используйте только обезличенные производные документы. Перемещение исходника в папку не скрывает его от посетителей публичного репозитория.

## 6. Следующие действия по организации

1. После проверки приватности назначить каждому исходнику стабильный ID `SRC-001`, `SRC-002` и т. д.
2. Для каждой значимой цитаты фиксировать ID источника, страницу/таймкод и контекст.
3. Разделить приватный архив первичных материалов и публичный набор обезличенных материалов.
4. Только после инвентаризации согласовать физическое перемещение исходников по папкам; пока исходные пути не менялись, чтобы не ломать ссылки и сохранить предсказуемость.
